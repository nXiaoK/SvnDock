# 冲突审阅与处理

发现冲突后，工作区顶部会显示冲突数量。点击 **显示冲突** 可清除搜索条件并只查看
冲突项目；点击 **审阅全部冲突…** 可打开当前工作副本的完整冲突清单。右键审阅时，
若点击的项目属于已有多选，会保留选择中的冲突范围，并说明排除的其他项目数量。
右侧检查器的处理入口只针对当前单个项目。

## 审阅范围

审阅页显示工作副本名称、本地路径、确切处理路径和冲突类型。左侧切换项目，右侧
预览当前工作状态与基线的差异；这不是替换后的预览，也不是三方合并编辑器。
无法读取差异或没有差异，都不能证明冲突已经解决。需要时在熟悉的编辑器或外部
合并工具中处理，再刷新差异并确认结果。

- **内容冲突**：检查文件内容。二进制文件需要用对应应用处理。
- **属性冲突**：核对并修正属性值，确认保留的是预期设置。
- **路径结构冲突**：先处理删除、移动或阻挡关系，检查目录和文件所在的位置。

审阅页固定本次处理的路径，不随主界面选择变化。它不会保存文件内容快照；真正
执行前会在工作副本锁内重新检查 SVN 状态、路径归属和冲突类型。

## 选择处理方式

默认 **保留当前工作状态（标记已解决）**，需要先确认已检查并处理清单中的项目。
这个动作不会自动合并内容或修正目录结构，只清除 SVN 冲突标记。

仅当本次全部项目都是单独的文件内容冲突时，才提供整文件使用本地版本、仓库传入
版本或共同基线的选项。它们会替换清单中各文件的全部内容，可能丢失当前编辑；
需要先保留需要的内容并明确勾选覆盖确认。符号链接、属性冲突、路径结构冲突及
混合类型的选择不提供整文件替换。

更改处理方式会清除确认勾选。关闭审阅页不执行处理；重新打开会生成新的审阅范围，
之前窗口中的确认不能用于新窗口。

## 执行结果

一次处理只作用于清单中的明确节点，不递归清除未选择的子项冲突。文件外部引用、
嵌套工作副本和越界符号链接需要在正确的工作副本中单独处理。

命令完成后，软件会在同一工作副本锁内重新查询这些路径，检查内容、属性和路径
结构冲突标记。只有核验通过才报告完成；仍有冲突时明确指出剩余路径。无法读取
最终状态或操作中断时，结果显示为待确认，不自动重试。

底部 **操作记录** 会保留处理策略、路径范围和结果。处理失败也可能改变了部分
项目，需要先刷新检查；处理成功不等于提交到仓库，若仍有需要保留的本地变更，
请审阅后提交。
