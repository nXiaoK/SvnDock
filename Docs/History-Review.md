# 提交历史与差异预览

历史检查器采用“提交记录 → 变更路径 → 文件差异”的浏览流程。保持当前 macOS
原生控件、系统深浅色外观、细分隔线与等宽代码字体，避免在窄侧栏中强行放置三列。

- 单击历史记录，在列表下方加载提交作者、时间、说明和本次提交的变更路径。
- 选择路径后自动读取历史差异；键盘方向键和预览标题栏的前后按钮可切换路径。
- 窗口高度不足时，选择提交会切换到占满检查器的详情；点击 **返回历史** 或按 Esc
  恢复原筛选、已载入页和所选位置。详情顶部可切换上一条／下一条匹配提交。
- 双击提交，或点击详情中的放大按钮，在独立窗口中并排显示文件列表和差异。
  独立窗口固定到所选工作副本及版本，不随主界面文件选择而改变。
- 路径搜索覆盖完整变更清单和复制来源。大量路径分批显示，清单底部可加载更多。
- 差异支持合并、并排、原文、变更块跳转和复制完整补丁。历史两侧明确显示版本号。
- 长提交说明可在弹出面板中完整阅读及复制；右键可以复制版本号、说明和仓库路径。

## 检索与定位

历史顶部显示当前范围：整个工作副本或选中的单个路径。输入说明、作者或版本号
可筛选**已载入的记录**；“限定作者”与关键词同时生效，不区分大小写。筛选不发起
服务器搜索。底部显示匹配数与已载入数，无匹配时仍可继续加载更早记录或清空筛选。

例如，在说明中搜索“登录”，再将作者限定为“王”，只显示已载入记录中该作者相关
的登录变更。逐页加载后，新读到的记录会自动应用同一筛选条件。

展开 **按版本号打开仓库详情**，输入 `r123` 或 `123`，可直接在独立窗口查看该次
提交，无需先加载到它所在的历史页。这里查询的是当前工作副本所属仓库，该提交可能
不涉及当前选中的路径；不存在或无权访问的版本由详情窗口给出错误和重试入口。
不接受版本区间、日期或 `HEAD` 等符号。

## 版本语义

普通变更比较 `r(N-1)` 与 `rN`。新增和删除的一侧为空；替换显示旧内容删除与
新内容添加。查询以仓库根地址及固定版本为基准，不读取当前工作副本中的文件内容，
因此文件在本地或 HEAD 中已经消失也可预览。

复制及移动比较记录中的来源路径、来源版本与目的路径的 `rN`；未改内容的复制
明确显示“与复制来源相同”。SVN 把移动记录为复制与删除，界面合并匹配的两端并
保留来源信息。目录本身只预览属性变更，其受影响的子文件单独列出。

详情表示该次仓库提交中可访问的全部变更路径，可能包含当前工作副本范围以外的
路径。使用详细日志保留复制信息，并结合版本摘要补齐目录复制或删除涉及的子文件。
二进制文件显示 SVN 说明，属性变更保留原文；不执行更新、还原、提交等写操作。

## 加载与错误

历史每次展示 100 条，并从当前最后一条的修订号向更早版本继续读取，移除原先
1,000 条的浏览上限。每页额外读取一条来判断是否还有历史，兼容修订号不连续的路径。
分页期间有新的仓库提交时，旧页不会因此重复或跳过；点击刷新才从最新版本重新载入
首批记录。切换检查器后返回相同目标会保留已载入的页。

下一页失败时保留列表，重试仍读取相同范围。刷新失败时保留此前记录并提示失败，
成功后替换为新的首批记录。本地刷新、更新和提交会使已有历史需要刷新，防止工作
副本发生变化后仍继续使用旧分页范围。切换工作副本或路径会清除不属于新目标的结果。

切换提交或路径时取消旧请求并检查请求标识，避免旧响应覆盖新选择。文件差异按需
加载，缓存最多 12 项、合计 8 MB。详情查询失败在当前区域显示原因及重试按钮，
不把错误当作“无差异”。
